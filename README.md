# Passing Tests Miss Edge Cases

This example demonstrates how a test suite can pass successfully, yet still fail to cover critical edge cases or validate crucial business rules. It features a simple price calculation function with an initial set of passing tests, followed by an exploration of scenarios that reveal the limitations and potential bugs missed by the superficial test coverage.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
